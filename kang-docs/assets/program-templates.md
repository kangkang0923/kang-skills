# 程序类项目模板

复制时把 `<...>` 替换掉；用不上的小节整段删掉，**不要留空标题**。

## `AGENTS.md`

````markdown
项目类型：程序类
# <项目名> · Agent 入口

## 这是什么
<一句话：给谁解决什么问题>

## 命令
```powershell
# 构建
<命令>
# 运行 / 自检（退出码含义）
<命令>
# 发布到交付目录
<命令>
```

## 硬约束（改代码前必读）
- <不变量 1>
- <不变量 2>
- 禁止：<绝不能做的事>

## 非直觉的坑
- <踩过一次就记住的事，写清现象与根因>

## 文档导航
| 文件 | 内容 | 状态 |
|---|---|---|
| `docs/REQUIREMENTS.md` | 要什么、验收标准 | ✅ |
| `docs/DESIGN.md` | 实现契约、不变量 | ✅ |
| `docs/PLAN.md` | 待办 | ✅ |
| `docs/MEMORY.md` | 当前状态、交接提示、临时环境 | ✅ |
| `docs/DECISIONS.md` | 为什么这么定 | ✅ |
| `CHANGELOG.md` | 版本变化 | ✅ |

## 当前状态
见 `docs/MEMORY.md`；下一步见 `docs/PLAN.md`，此处不复述。
````

## `docs/REQUIREMENTS.md`

```markdown
# 需求

> 用户拥有需求决定权。AI 只能提炼用户原话和已确认结论，经用户明确确认后代写；发现歧义必须问，不许自行推测。

## 目标

## 必须做到（每条都能验收）

## 明确不做

## 验收标准
| # | 标准 | 怎么验 |
|---|---|---|
| 1 | | |

## 约束（供选型使用）
- 平台与运行位置：
- 长期维护者会什么：
- 现成环境：
- 数据与账号：
- 硬约束：
- 失败代价：
```

## `docs/DESIGN.md`

```markdown
# 设计（实现契约）

> 本文档不含进度（进度见 `MEMORY.md`），不含理由（理由见 `DECISIONS.md`）。

## 技术栈
<最终栈 + 版本号；只此一处>

## 结构
| 模块 | 职责 |
|---|---|

## 数据模型
<配置格式、字段含义、禁止手工修改的字段>

## 核心流程 / 算法

## 不变量（违反任何一条 = 实现错误）
| # | 不变量 |
|---|---|

## 验证方式
<自检、断言、实机清单>
```

## `docs/PLAN.md`

```markdown
# 计划

> 当前：<一句话，含日期>

## 待办
- [ ] <事项>（`(假设)` 标记未验证的前提）

## 近期完成（保留最近 20 条，更早的已归档进 CHANGELOG）
- [x] <事项>（YYYY-MM-DD）
```

## `docs/MEMORY.md`

```markdown
# 当前状态

> 覆盖式：只反映现在。历史看 git 或 `CHANGELOG.md`。最后更新：YYYY-MM-DD

## 做到哪了
- <一句话写当前阶段，不是过程；下一步见 `PLAN.md`，不复制任务>

## 交接提示
- <只写其他文档没有的临时背景；长期有效的坑放 `AGENTS.md`>

## 环境与部署
- <只能在某台机器/某个目录下做的事；稳定命令放 `AGENTS.md`>
```

## `docs/DECISIONS.md`

```markdown
# 决策记录

> 只追加，不修改。允许杂。

### D-001 <标题>
- 结论：
- 理由：
- 被否方案：
- 取代：（可选，填 `D-xxx`；没有则删除本行）
- 日期：YYYY-MM-DD
```
