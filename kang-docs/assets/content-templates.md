# 内容类项目模板

与程序类的差别：没有构建/测试命令；`DESIGN.md` 写「内容组织方式」而不是技术架构；`CHANGELOG` 按月份而不是版本号；`REQUIREMENTS.md` 写选题要求与收录标准。

## `AGENTS.md`

```markdown
项目类型：内容类
# <项目名> · Agent 入口

## 这是什么
<一句话：什么主题的资料/笔记，给谁看>

## 文件与命名规则
- 目录层级：<例：按主题分目录，不按日期>
- 文件名：<例：`NN 主题.md`，中文，不带日期前缀>
- 图片：<放哪、怎么引用>

## 禁止
- 禁止改动：<原始资料 / 他人作品 / 已定稿内容>
- 禁止：在根目录留草稿

## 文档导航
| 文件 | 内容 | 状态 |
|---|---|---|
| `docs/REQUIREMENTS.md` | 收录标准、验收 | ✅ |
| `docs/DESIGN.md` | 内容组织方式 | ✅ |
| `docs/PLAN.md` | 待办 | ✅ |
| `docs/MEMORY.md` | 当前状态、交接提示、临时环境 | ✅ |
| `docs/DECISIONS.md` | 为什么这么整理 | ✅ |
| `CHANGELOG.md` | 按月份的改动概要 | ✅ |
```

## `docs/REQUIREMENTS.md`

```markdown
# 要求

> 用户拥有需求决定权。AI 只能提炼用户原话和已确认结论，经用户明确确认后代写；不许自行推测。

## 目的
<这份资料/笔记对谁有用，用来做什么>

## 收录标准
- 收：<什么值得记>
- 不收：<什么不记>

## 组织要求
- <例：一个主题一个文件；一篇不超过 N 字>

## 验收
| # | 标准 | 怎么验 |
|---|---|---|
```

## `docs/DESIGN.md`

```markdown
# 内容组织方式

> 本文档不含进度。进度见 `MEMORY.md`。

## 目录与层级
## 命名规则
## 标签 / 分类体系
## 交叉引用方式
## 图片与附件存放
```

## `docs/PLAN.md`

```markdown
# 计划

> 当前：<一句话，含日期>

## 待办
- [ ] <要补的主题>

## 近期完成（保留最近 20 条）
- [x] <主题>（YYYY-MM-DD）
```

## `docs/MEMORY.md`

```markdown
# 当前状态

> 覆盖式。最后更新：YYYY-MM-DD

## 做到哪了
<只写当前阶段；下一步见 `PLAN.md`，不复制任务>

## 交接提示
<只写其他文档没有的临时背景；长期规则放 `AGENTS.md`>
```

## `docs/DECISIONS.md`

```markdown
# 决策记录

> 只追加，不修改。

### D-001 <标题>
- 结论：
- 理由：
- 被否方案：
- 取代：（可选，填 `D-xxx`；没有则删除本行）
- 日期：YYYY-MM-DD
```

## `CHANGELOG.md`

```markdown
# 改动概要

> 只写「加了什么主题 / 删了什么」，不写具体条目。

## 2026-10
### 新增
### 调整
### 删除
```

```markdown
<按主题列出>

见 `AGENTS.md` 的导航表。
```
