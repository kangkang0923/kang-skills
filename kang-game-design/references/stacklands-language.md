# 堆叠大陆卡牌语言词典（宿主侧）

> **定位**：把堆叠大陆原生交互整理成「词汇表」，做机制映射时先查这里有没有现成表达。分两层：**玩法语言**（玩家可感知的原生交互，可与用户直接讨论——用户玩堆叠大陆）与**引擎能力**（实现边界，必须以反编译为准）。

## 玩法语言词汇表

| 词汇 | 原生形态 | 映射提示 |
|---|---|---|
| 叠放 | 卡叠到目标卡上 = 对它做某事 | 通用「动词」：采集、加工、喂食、捕捉…… |
| 读条 | 叠放后计时完成 | 延时产出、传送门、仪式感动作 |
| 放置式劳作 | 卡放在工位上持续干活 | D-011 拍板的劳作交互 |
| 转化 | 物品组合变新卡（原版先例：猴+香蕉→驯化猴） | 捕捉/孵化/升星类机制的原型 |
| 开包 | 金币买卡包随机出卡 | 随机性 + 经济 sink + 收集驱动 |
| 想法/蓝图 | 获得想法卡解锁配方（合成配方的解锁层） | 原生「科技树」——科技类机制的首选替代 |
| 合成 | 蓝图+材料堆一起出产物 | 生产链表达 |
| 战斗 | 卡对卡自动交战 | 数值乘区可接（克制/被动词条） |
| 月末结算 | 每游戏月底喂食结算 | 喂食/定期消耗类机制的天然挂点 |
| 金币/卖卡 | 卖卡换金币、金币买包 | 通用经济回路 |
| 时间循环 | 游戏月为周期 | 冷却/生长/节奏单位（塔 3 月冷却即此） |
| Board | 独立地图；船是原版唯一跨图通道 | 帕鲁岛隔离（I1/I2 不变量）的基础 |

## 引擎能力：已核实清单（引用须带出处）

以下行号引自项目文档，以原出处为准；更多见 `stacklands-palworld/docs/Spike-技术前置分析.md` 与 mod-common 知识库：

- 劳作工位收人判 `is BaseVillager`（GS:14090）→ 继承 BaseVillager 即被所有原版工位接受，零补丁
- 劳作速度乘区 `GetActionTimeModifier`（GS:8079）→ 适性速度已接
- `WorldManager.GoToBoard` public（GS:42744）→ 视角门
- `WorldManager.ChangeToCard`（GS:43283）→ 捕捉/转化的底层调用
- 原版跨 Board 通道只有船，航线固定原版岛 id（GS:8884）→ 自建岛天然隔离
- `[TimedAction]` 必须是卡脚本类的实例方法（S20 坑）
- `CombatStats` prefab 为共享（改数值须克隆，不能改共享件）

## 断言纪律

- 说「引擎做得到/做不到」之前：先查核实处（`stacklands-mod-common/decompiled/GameScripts/GameScripts.decompiled.cs`、mod-common 知识库、Spike 分析）；找到 → 引用出处；找不到 → 写「未核实」，进 PLAN.md 待验证
- mod 已动过引擎行为的部分，以 `stacklands-palworld/docs/DESIGN.md` 的「不变量」节为准；设计不得与 I1~I5 冲突，除非显式重开对应决策
- 本文件的词汇表是玩法层归纳，新词条（原版还有仓库、卡堆上限、探索包等细节）以游戏实机与反编译为准，发现遗漏可增补并注明依据
